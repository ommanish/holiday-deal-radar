# Deal Radar

A lightweight GitHub Pages dashboard for curated, source-linked holiday deals. It does **not** copy retailer content or automatically scrape retailer pages. Deals are vetted and linked to official retailer offer pages.

## Publish with GitHub Pages

The included GitHub Actions workflow deploys the static site from `main`.

## Updating offers

Edit `app.js` with the verified product, retailer, current price, verifiable comparison price, condition, direct official URL, and terms. Do not use marketplace items unless seller, item condition, and return terms are clear.

## Editorial standard

- Official retailer or manufacturer source required.
- No affiliate links.
- Open-box/refurbished condition stated upfront.
- Avoid unverified “was” prices.
- Recheck availability before publishing.
